# Tithe

A gothic black-and-crimson game deals app for iPhone. It compares PC game prices across Steam, GOG, Epic, Humble, Fanatical, Green Man Gaming and other stores, using CheapShark. No account or key is needed.

- **Offerings:** today's deals, sorted by best deal, biggest discount, cheapest, newest, Metacritic or Steam reviews. Filter by store, maximum price or big releases only.
- **Seek:** search any game and see every store's price, plus the lowest price ever. Tap a store to open the deal.
- **Vigil:** watch games at a target price. Tithe checks in the background (iOS decides how often, usually every few hours) and whenever you open it, and sends a notification when any store reaches your price.
- **Sanctum:** show prices in pounds, euros or dollars. CheapShark's prices are in US dollars, so pounds and euros are close estimates at today's exchange rate.

Build: **Actions → Build Tithe IPA**, then install **Tithe-ipa** with Sideloadly.
