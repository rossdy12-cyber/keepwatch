# Vespers

A gothic black-and-crimson calendar for iPhone. It shows and edits the calendars already on the phone (iCloud, Google, Outlook, Exchange, subscribed calendars), so it needs no server or account of its own.

- **Month:** a crimson month grid headed by the month in blackletter with the year in Roman numerals. Coloured dots show each day's events. Swipe sideways to change month; the selected day's events are listed below.
- **Agenda:** the coming 60 days, day by day ("Look further ahead" adds more).
- **Events:** add, edit and delete, with all-day, repeat, alert, link and notes. For repeating events you choose this one only or all future ones.
- **Calendars:** the books icon hides or shows each calendar.

Build: **Actions → Build Vespers IPA**, then install **Vespers-ipa** with Sideloadly. On first launch, allow **Full Access** to calendars.
