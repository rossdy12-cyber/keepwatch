# Ossuary

A gothic black-and-crimson game launcher for the games on your NAS.

- **Crypts:** one arched window per system with its game count, and search across every system.
- **Games:** box art grids. Each game page shows the system, file and size, and **Carry it to this iPhone** downloads it with a progress bar.
- **Lately Risen:** the most recently added games.
- **Carried:** games on this iPhone, which you can share or delete. They're also in the Files app under **On My iPhone › Ossuary**.

**Playing in RetroDeck:** download the game, then in RetroDeck use **Import ROMs → Browse → On My iPhone → Ossuary**. NES, SNES, Game Boy, GBA, N64, DS, Mega Drive and PlayStation games are marked as RetroDeck-playable.

Set up the server first: see [`../ossuary-server`](../ossuary-server/README.md). Then build with **Actions → Build Ossuary IPA**.
